# Cloud Burst Early Warning & Alarm System

**Project ID:** SKIT/AI/2023-2027/09 | **Branch:** CSE (AI), Section A  
**Track:** Hardware-based Project | **SDG:** 11 (Sustainable Cities & Communities), 13 (Climate Action)

## Problem Statement
Develop a real-time early warning and alarm system for cloudbursts in hilly regions by integrating distributed environmental sensors, weather/radar data and AI/ML-based rainfall anomaly prediction. The system should continuously monitor atmospheric conditions and alert authorities, including during poor connectivity.

## Tech Stack
| Component | Purpose |
|---|---|
| ESP32 / Raspberry Pi | Sensor data collection and system control |
| Rain gauge + BME280 pressure sensor | Rainfall and atmospheric monitoring |
| LoRa / LoRa Mesh | Long-range sensor data transmission |
| Python + FastAPI + ML + Dashboard | Data processing, prediction and monitoring |
