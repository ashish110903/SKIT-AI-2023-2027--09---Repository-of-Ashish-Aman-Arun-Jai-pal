# Hardware Component Specifications

- **Microcontroller**: ESP32-WROOM-32 (Dual-core 240MHz, 520KB SRAM)
- **Barometric Pressure**: Bosch BME280 (I2C, 300-1100 hPa, +-1 hPa accuracy)
- **Rain Gauge**: Misol Tipping Bucket (0.2794 mm/tip reed switch interrupt)
- **Long Range Radio**: Semtech SX1276 LoRa transceiver (433MHz, +20dBm PA)
